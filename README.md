# Elbow Arcade Privacy Policy Website

Static privacy-policy site for the Elbow Arcade iOS/iPadOS app.

## Before publishing

Replace all placeholders in `index.html`:

- `[INSERT EFFECTIVE DATE]`
- `[INSERT DATE]`
- `[INSERT LEGAL COMPANY OR INDIVIDUAL NAME]`
- `[INSERT PRIVACY EMAIL]`
- `[INSERT BUSINESS ADDRESS, IF REQUIRED]`
- `[INSERT POSTAL ADDRESS, IF REQUIRED]`

Do not publish the site with placeholder legal/contact information.

## GitHub Pages

Enable GitHub Pages for the repository using:

- Settings
- Pages
- Deploy from a branch
- Branch: `main`
- Folder: `/ (root)`

The privacy policy will then be available at the repository's GitHub Pages URL.

## App Store

Use the published HTTPS page as the App Store Connect Privacy Policy URL. Apple requires a privacy-policy URL for all apps, and HealthKit apps also require a coherent privacy policy.

## Important legal note

This template is designed to match the intended Elbow Arcade architecture: local-only motion processing, no developer backend, optional HealthKit writing, and no third-party analytics or advertising. Review it with qualified privacy counsel before relying on it as a legal compliance document, especially for GDPR/EEA, UK GDPR, Swiss, California, or other local requirements.
